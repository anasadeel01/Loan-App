# 💰 LOAN PREDICTION WEB APPLICATION

A machine-learning-powered web application that predicts loan approval outcomes based on applicant information. The project combines a trained machine learning model with a Flask-based web application to provide an interactive and user-friendly loan prediction experience.

The application demonstrates an end-to-end machine learning workflow — from dataset preparation and model training to model integration and real-time predictions through a web interface.

---

## 🚀 FEATURES

- 🤖 Machine Learning-Based Loan Prediction
- 🌐 Interactive Web Application
- 📊 Applicant Data Processing
- 🧠 Trained Machine Learning Model
- 🔄 Real-Time Prediction through the Web Interface
- 🎨 User-Friendly Frontend
- 📁 Organized Dataset and Model Storage
- ⚙️ Separate Model Training Pipeline

## ⚙️ INSTALLATION

1. Clone the Repository
git clone https://github.com/anasadeel01/Loan-App.git
cd Loan-App
2. Create a Virtual Environment
python -m venv .venv
3. Activate the Virtual Environment
Windows
.venv\Scripts\activate
macOS / Linux
source .venv/bin/activate
4. Install Dependencies
pip install -r requirements.txt

## 🧠 TRAIN THE MACHINE LEARNING MODEL

To train or retrain the machine learning model using the available dataset:

python train_model.py

The trained model is stored in the model/ directory and is used by the web application to generate predictions.

▶️ Run the Application

Start the Flask application using:

python app.py
